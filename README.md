# NTP Network Time Protocol

Lekka aplikacja webowa (HTML, CSS, JavaScript) do podglądu czasu lokalnego, zarządzania listą serwerów NTP oraz ręcznej synchronizacji z podglądem logów.

## Funkcje
- **Zegar czasu rzeczywistego** z milisekundami oraz trybem pełnoekranowym (`F` lub przycisk w nagłówku).
- **Zarządzanie serwerami NTP** — wybór serwera, dodawanie własnych wpisów (zapis w `localStorage`) oraz usuwanie serwerów własnych.
- **Ręczna synchronizacja** z konsolą logów.
- **Eksport konfiguracji** listy serwerów do formatów **CSV** oraz **JSON**.

## Uruchomienie
Otwórz plik `index.html` bezpośrednio w dowolnej przeglądarce internetowej.
